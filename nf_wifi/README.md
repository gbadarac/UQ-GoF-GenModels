# Normalizing-flow ensembles (App. B)

This is the code behind App. B of *An end-to-end framework for uncertainty-aware validation of generative models*:
ensembles of normalizing flows, the w_i f_i weight fit with its sandwich covariance, and the goodness-of-fit test with
the point and Gaussian composite nulls (Figs. 10–13).

The files are copied byte-for-byte from the analysis repository, keeping its directory layout so that the relative
imports between them still resolve. Nothing has been edited. Files the paper does not use (the kernel-ensemble
backend, the with-replacement null sampler `LRT.py`, notebooks, other Sparker utilities) are left out.

## Running

The pipeline runs in four steps, each driven by a SLURM script:

1. **Data.** Generate the 2D toy (`python generate_2d_gaussian_heavy_tail_target_data.py`) and build the 4D split
   from the jet-embedding files (`make_qcd_cache.py`, then `carve_heldout_qcd.py`).
2. **Flows.** `sbatch submit_NFnflows_2d.sh` (2D) or `submit_NFnflows.sh` (4D) trains the pool of 512 flows as an array
   job.
3. **Weights.** `submit_fit_weights.sh` selects each ensemble choice (`select_member_seeds.py`) and fits its weights
   and covariance.
4. **Test.** `run_nf_scan.sh` submits the whole campaign through `submit_LRT_toys.sh`, which calls `LRT_rejnull.py`:
   - 10 choices × N_test × {single flow, M = 32, M = 128} × {point, composite};
   - null and observed toys.

   For example, `DRYRUN=0 DIM=2d ./run_nf_scan.sh`. The 4D campaign uses `DIM=4d SIGMA=0.53`.

Then `python LRT/plot_pvalue_ladder_paper.py --dim 2d` (or `4d`) draws Figs. 12 and 13 from the results tree.

The SLURM scripts are the drivers used for the paper, on the ETH Zürich cluster, and still contain that cluster's
absolute paths. Before running elsewhere, set:
- `REPO_ROOT` (in `submit_LRT_toys.sh`, `run_nf_scan.sh`, `submit_fit_weights.sh`, `eval_gridsearch.py`);
- the conda paths (`/work/.../miniforge3`);
- the `#SBATCH` log paths, account and partition.

The `prefix:` lines in `envs/*.yml` can be dropped.

## Settings used in the paper

| | 2D toy | 4D jets |
|---|---|---|
| flows | 4 MADE-RQS layers, 4 blocks, hidden 64, 8 bins | 6 layers, 8 blocks, hidden 128, 10 bins |
| pool / ensembles | 512 flows; M = 1, 32, 128; 10 choices each | same |
| kernels | J = 500, σ = 0.4 | J = 500, σ = 0.53 |
| regularization | ridge λ = 1, box A = 3 | same |
| toys | B = 100 null toys, 100 observed sets per (choice, N_test) | same |

Trained flows and test results are not included: they are large and are regenerated by steps 2–4.
